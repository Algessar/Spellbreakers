# 27. What Is Fundamental

The following defines the identity of Spellbreakers.

### Combat

- Lichtenauer-inspired longsword combat
    
- A small set of meaningful guards
    
- Vom Tag
    
- Pflug
    
- Alber
    
- Ochs
    
- Langort
    
- Iron Gate
    
- Guard transitions as attacks
    
- Passing through guards as the core attack-selection mechanic
    
- Timing-based combat
    
- Parrying
    
- Distance and positioning
    
- Readable enemy behavior
    
- Terrain affecting combat
    
- Meaningful attack lines
    
- Responsive combat movement
    

### Exploration

- Zelda-inspired exploration
    
- Physical 3D environments
    
- Environmental interaction
    
- Relatively simple puzzles
    
- Discoverable paths and locations
    
- Spaces large enough for meaningful navigation and combat
    

### World

- Bright-ish medieval atmosphere
    
- 13th–14th-century inspiration
    
- Grounded medieval visual language
    
- Fantasy elements without abandoning the medieval foundation
    

### Difficulty

- More demanding than casual Zelda
    
- Less punishing than Dark Souls
    
- Skill primarily comes from understanding the systems
