# 29. Development Priority

When making implementation decisions, prioritize:

1. **Combat feel**
    
2. **Guard/transition clarity**
    
3. **Timing and responsiveness**
    
4. **Targeting reliability**
    
5. **Combat locomotion**
    
6. **Readable enemy behavior**
    
7. **Distance and positioning**
    
8. **Combat-aware level geometry**
    
9. **Exploration**
    
10. **World-building and presentation**
    
11. **Secondary systems**
    

The project should repeatedly answer:

> **Does this make the sword fighting or exploration better?**

If a feature does not contribute to the intended experience, it should justify its existence before becoming part of the core game.
