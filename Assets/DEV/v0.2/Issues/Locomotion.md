# Locomotion

Current in-stance locomotion feels too slow relative to normal movement.

This is currently a significant source of perceived clunkiness.

Combat movement should allow the player to:

- approach
    
- retreat
    
- circle
    
- maintain measure
    
- react to attacks
    

without making combat stance feel like a dramatically slower movement mode.

The exact movement speed is not yet fixed.

The important goal is:

> **Combat should remain physically deliberate without becoming sluggish.**
