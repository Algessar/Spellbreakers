# Combat and Environment

Combat should not be confined to featureless arenas.

Positioning is part of swordsmanship.

The environment should affect:

- distance
    
- available attack angles
    
- circling
    
- footwork
    
- escape routes
    
- guard selection
    
- attack viability
    

Useful combat environments may include:

- narrow gates
    
- doorways
    
- stairs
    
- walls
    
- ruins
    
- uneven terrain
    
- confined interiors
    
- open fields
    

Level geometry is therefore part of the combat system rather than merely scenery surrounding it.
