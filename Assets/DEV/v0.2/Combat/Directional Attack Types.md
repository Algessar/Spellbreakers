# 11. Directional Attack Types

The primary attack lines currently include:

- **Oberhau** — downward diagonal
    
- **Mittelhau** — horizontal
    
- **Unterhau** — upward diagonal
    
- **Thrust / Stichen** — direct point attack
    

These describe the attack's line and motion.

They should not automatically be treated as independent "attack buttons."

They are properties of the transition between combat states.
