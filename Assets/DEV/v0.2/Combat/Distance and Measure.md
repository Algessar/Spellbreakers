# Distance and Measure

Distance is a fundamental part of combat.

The system should distinguish between different ranges of engagement, including the conceptual HEMA phases:

- **Zufechten** — outside / approaching measure
    
- **Krieg** — close combat / blade contact
    
- **Ringen** — grappling
    

Not every phase needs to be implemented immediately.

The important principle is that **distance changes which attacks and transitions are useful**.

Some transition descriptions therefore depend on distance.
