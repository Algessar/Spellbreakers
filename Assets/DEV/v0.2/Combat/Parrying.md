# 13. Parrying

Parrying is a core combat mechanic.

The player should be rewarded for correctly reading and timing defensive responses.

The intended interaction is:

```
Enemy attack
     ↓
Player reads transition
     ↓
Correct defensive timing
     ↓
Blade contact / parry
     ↓
Enemy loses initiative
     ↓
Opening
```

A **perfect parry stagger** is planned.

A perfect parry should therefore create a meaningful tactical advantage rather than simply producing a numerical damage reduction.
